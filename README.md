Aplicação web para gerenciamento de finanças pessoais com interface moderna e responsiva. Permite controle completo de receitas e despesas com visualização intuitiva e filtragem de dados.

## ✨ Funcionalidades

- ✅ Autenticação de usuários (Login/Cadastro)
- ✅ Dashboard com visão geral das finanças
- ✅ Cadastro de receitas e despesas
- ✅ Edição e exclusão de transações
- ✅ Filtros e busca de transações
- ✅ Interface responsiva e moderna
- ✅ Navegação fluida entre páginas

## 🚀 Como Executar

### 📋 Pré-requisitos

```
Node.js (versão 18 ou superior)
npm ou yarn
Git
```

### 🔧 Instalação

1. Clone o repositório:
```bash
git clone https://github.com/emanuel-henrique/Finance_Tracker-FrontEnd.git
cd Finance_Tracker-FrontEnd
```

2. Instale as dependências:
```bash
npm install
```

3. Configure as variáveis de ambiente criando um arquivo `.env`:
```env
VITE_API_URL=http://localhost:3000
```

4. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

A aplicação estará rodando em `http://localhost:5173`

## 🛠️ Tecnologias

- [React](https://react.dev/) - Biblioteca JavaScript para interfaces

- [Tailwind CSS](https://tailwindcss.com/) - Framework CSS utility-first

## 🎨 Componentes UI

Este projeto utiliza componentes do **shadcn/ui**, que oferecem:
- Design system consistente
- Componentes acessíveis (a11y)
- Totalmente customizáveis com Tailwind

## 🔗 Integração com Backend

Esta aplicação consome a API REST do Finance Tracker BackEnd:
- **Repositório Backend**: [Finance_Tracker-BackEnd](https://github.com/emanuel-henrique/Finance_Tracker-BackEnd)
- **Autenticação**: JWT Bearer Token
- **Endpoints**: Usuários, Transações e Sessões

Certifique-se de que o backend esteja rodando antes de iniciar o frontend.
